# Decorator structural Design Pattern

The Decorator Design Pattern is a structural pattern used to dynamically add new behavior or responsibilities to an object without modifying its existing code. It follows the principle of composition over inheritance and provides a flexible alternative to subclassing.


## Key Features
1. Extends functionality dynamically – New behavior can be added at runtime.
2. Follows Open-Closed Principle – The existing code remains unchanged, but its behavior can be enhanced.
3. Uses composition – A decorator wraps around the original object.
4. Multiple decorators can be stacked – This allows for flexible combinations of functionalities.
