# Facade Structural Design Pattern

The Facade pattern is a structural design pattern that provides a simplified, unified interface to a set of interfaces in a subsystem. It hides the complexities of the subsystem and provides a single entry point to clients, making the subsystem easier to use.

## Key Features of Facade Pattern
1. Simplifies Client Interaction – Provides a simple API to interact with complex subsystems.
2. Reduces Dependency – Clients don’t need to know about internal subsystem details.
3. Improves Maintainability – Changes in subsystem components do not affect clients directly.
4. Encapsulates Complexity – Internal working of subsystems is hidden from the client.
